# projet-red_lesElyx

## Présentation
Mini jeu vidéo en ligne de commande (CLI) développé en Go dans le cadre du Projet RED (Ynov).

Zeyla est une aventurière dotée de pouvoirs qui grimpe les échelons du **Zénith**, un lieu mystique où chaque niveau est gardé par un **Gardien du Seuil**. Elle doit le vaincre en combat tour par tour pour gagner en puissance et poursuivre son ascension.

## Fonctionnalités
- Création de personnage (nom, classe : Humaine / Elfe / Naine)
- Gestion d'inventaire (limite de places, augmentable)
- Marchande : achat de potions, ressources et sorts
- Forge : fabrication d'équipement à partir de ressources
- Combat tour par tour (attaque, objets, sort)
- Système de progression par niveaux

## Installation
1. Installer Go si ce n'est pas déjà fait : https://go.dev/dl/
2. Cloner ce dépôt :
```
git clone https://github.com/mbaycoundoul40-boop/projet-red_lesElyx.git
```
3. Se placer dans le dossier du code source :
```
cd projet-red_lesElyx/src
```

## Lancement
```
go run main.go
```
